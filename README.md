# 🚀 Virtual Enterprise - Fábrica de Micro-SaaS Autónoma con Agentes de IA

Plataforma autómata construida con **Next.js 14, Tailwind CSS, TypeScript, Firebase y Google Cloud Gemini 1.5 Flash**.

## 🛠️ Estructura del Proyecto
- `src/lib/agents/`: Departamentos de IA (Discovery, Product, Growth, Engineering, Deploy).
- `src/lib/validations/contracts.ts`: Esquemas estricto Zod para comunicación interagente.
- `src/lib/firebase/`: Conectores a Firestore NoSQL, Auth, Storage y Rules.
- `src/components/dashboard/`: Panel web interactivo con flujo Human-in-the-Loop (HITL) y tablero Kanban.

## 🚀 Inicio Rápido
```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) en su navegador.
